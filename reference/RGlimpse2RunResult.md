# A completed RGlimpse2 child-process operation

A completed RGlimpse2 child-process operation

## Usage

``` r
RGlimpse2RunResult(
  operation = character(0),
  outputs = list(),
  status = integer(0),
  stdout = character(0),
  stderr = character(0)
)
```

## Arguments

- operation:

  Stable operation identifier.

- outputs:

  Named output paths produced by the operation.

- status:

  Child-process exit status.

- stdout:

  Captured standard output.

- stderr:

  Captured standard error.
